# Comercial Bragantino — V4 Online

Aplicativo web/PWA para controle de fiados.

## Deploy
Projetado para hospedagem Node.js, especialmente Render, com repositório GitHub.

Arquivos importantes:
- `index.html` — interface mobile/PWA
- `server.js` — servidor
- `package.json` — dependências e start
- `render.yaml` — configuração do Render
- `manifest.webmanifest` — instalação como app
- `sw.js` — service worker/PWA
- `GUIA_HOSPEDAGEM_ONLINE.md` — passo a passo
